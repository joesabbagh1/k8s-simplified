SCHEDULING

The scheduler picks a node

The Pod exists, but nothing runs it yet: its spec.nodeName is empty. The scheduler watches for exactly these Pods. It drops nodes that can't fit the Pod's CPU and memory requests, scores the rest, and writes its pick back to the API server as a Binding.
